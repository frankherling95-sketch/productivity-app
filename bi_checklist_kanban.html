GitHub Gist koppelen

Je data wordt opgeslagen als een private Gist in je GitHub-account — toegankelijk op elk apparaat.

  1. Ga naar github.com/settings/tokens/new
  2. Naam: bijv. bi-checklist
  3. Scope: gist
  4. Klik Generate token en kopieer hem
Het token wordt alleen lokaal opgeslagen (localStorage).
