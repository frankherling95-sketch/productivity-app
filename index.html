Agenda's beheren

Voor de meeste gebruikers is het eenvoudiger om afspraken direct in deze app aan te maken (knop + Nieuwe afspraak) of een bestaand .ics bestand te importeren. Externe agenda-bronnen zijn voor wie automatisch wil syncen.

iCal links
📅 Outlook-agenda koppelen via iCal-link

Voor live synchronisatie publiceer je je Outlook-agenda als iCal-link en plak je die hierboven. Werkt voor zowel persoonlijke (outlook.com / hotmail.com / live.com) als werk-/school-accounts (mits niet door IT geblokkeerd).

  1. Ga naar outlook.live.com (persoonlijk) of outlook.office.com (werk)
  2. Klik op het tandwiel rechtsboven → View all Outlook settings
  3. Open Calendar → Shared calendars
  4. Bij Publish a calendar: kies de agenda + permissie "Can view all details" → Publish
  5. Kopieer de ICS-link (eindigt op .ics) — niet de HTML-link
  6. Plak hierboven via + iCal link toevoegen

ⓘ Microsoft cached publicatie-feeds, updates kunnen 15-30 min vertraging hebben. Is de publish-optie grijs of weg? Dan heeft IT het op tenant-niveau uitgezet — gebruik in dat geval handmatig File → Save Calendar (.ics) en importeer via de ICS-import knop.
